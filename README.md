# MERN-Stack 🚀

A collection of full-stack web applications built using the **MERN stack** (MongoDB, Express.js, React, Node.js) along with **Next.js** for select projects. This repository serves as a showcase of different real-world applications, each demonstrating different features, architectures, and use cases.

---

## 📂 Projects Included

### 1. [Authentication-full-stack-app](./Authentication-full-stack%20app)
A complete authentication system built with the MERN stack, featuring secure user sign-up, login, and session/token-based authentication and OTP Verificarion.

### 2. [Blog-Website](./Blog-Website)
A full-stack blogging platform where users can create, edit, and manage blog posts. Includes a deployed backend.


### 3. [MedLink](./MedLink)
A full-stack hospital management system built with Next.js and MongoDB. Includes dedicated dashboards for admins, doctors, and patients, appointment booking, authentication, and a clean, responsive UI.

### 4. [SafeCity](./SafeCity)
A full-stack platform where citizens can report issues and track them in real time. Built with React and Node.js, it includes separate dashboards for citizens and admins, secure login, and automatic email updates.

---

## 🛠️ Tech Stack

- **Frontend:** React, Next.js, JavaScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Deployment:** Vercel

## 🚀 Getting Started

Each project folder contains its own setup and installation instructions. In general:

```bash
# Clone the repository
git clone https://github.com/abdulbasir21/MERN-Stack.git

# Navigate into a specific project
cd MERN-Stack/<project-folder-name>

# Install dependencies
npm install

# Run the development server
npm run dev
```

> Refer to each project's individual README (if available) for environment variables and additional configuration.
