## Brand & Style

This design system establishes an authoritative, high-precision aesthetic tailored for construction executives, project engineers, and dispute resolution teams. It bridges the tangible reliability of heavy civil infrastructure with the velocity and kinetic refinement of modern developer platforms like Linear and Vercel. 

### Core Personality & Atmosphere
- **Structural Integrity:** Unflinching, dependable, and calibrated. Interfaces echo architectural draftsmanship with surgical alignments and intentional micro-borders.
- **Cognitive Clarity:** Dense commercial construction telemetry (submittals, change orders, BIM spec differences, and cost variance) presented with balanced visual pacing, suppressing clutter while offering rapid scanning.
- **Actionable Vigilance:** Proactive AI discovery signals are authoritative rather than speculative, leveraging deep architectural slate tones punctuated by vivid interactive blues and safety markers.

### Visual Architecture
The style fuses **Modern Technical Corporate** with **Micro-Architectural Tactility**:
- Fine 1px blueprint framing lines (#E6ECF5) and faint background grid textures ground the workspace.
- High-contrast structural surfaces with Deep Navy anchor primary navigation and command menus, while crisp white surface planes float over a soft steel canvas.
- Functional states borrow the utilitarian signifiers of the job site—safety amber warnings, approved structural greens, and high-voltage AI violet indicators.

## Colors

The color palette translates physical steel, job-site safety equipment, and architectural schematics into a digital workspace.

### Palette Architecture
- **Primary (`#2563EB` - Electric Blue):** Powers high-intent interactions, active tabs, primary commit actions, and AI target selectors.
- **Secondary (`#0A1A33` - Deep Navy):** Deployed for high-density structural anchoring—full-height sidebars, master data headers, terminal modals, and primary typography.
- **Tertiary (`#F59E0B` - Safety Amber):** Reserved for unreviewed scope deltas, field warnings, budget overrun warnings, and critical metrics requiring manual triage.
- **Neutral Canvas (`#F4F7FB` - Soft Canvas):** Replaces clinical stark white canvas backgrounds with a cool, low-fatigue slate base that lets white floating cards emerge naturally.

### Semantic Tones & Specialized Layers
- **Approved / Conforming (`#16A34A`):** Contract-cleared scope additions, approved RFI variations, balanced ledger rows.
- **Rejected / Critical Conflict (`#DC2626`):** Document contradictions, schedule collisions, unlicensed spec modifications.
- **AI Investigation Violet (`#7C3AED`):** Optical delta scans, automatic cross-document clause comparisons, and predicted risk indices.
- **Structural Borders (`#E6ECF5`):** Monolithic 1px boundary line used consistently across all cards, table cells, and navigation splitters.

## Typography

The typographic hierarchy coordinates three purpose-driven typefaces:

1. **Plus Jakarta Sans (Headings):** Selected for structural weight, geometric confidence, and tight horizontal tracking. It renders dashboards, KPI figures, and module titles with executive weight.
2. **Inter (Body & Controls):** The default workhorse for tabular figures, property inspectors, interactive forms, and analytical descriptions. Inter guarantees high readability across dense visual configurations.
3. **JetBrains Mono (Technical Spec & Identifiers):** Formats master specification codes (e.g., `Section 08 51 13 - Aluminum Windows`), blueprint coordinate stamps, revision hashes, change order numbers, and currency calculations. It prevents character confusion when auditing line-item numbers.

## Layout & Spacing

The layout is built on a 12-column dynamic fluid grid pinned between a fixed navigational spine (Deep Navy `#0A1A33`, 260px desktop width) and an optional contextual audit drawer (380px inspector panel).

### Breakpoints & Adaptive Rhythm
- **Desktop (≥ 1280px):** 12-column grid, `margin-lg` (2.5rem) outer padding, `gutter-lg` (2rem) columns. Workspace supports side-by-side spec document diffing.
- **Tablet (768px - 1279px):** 8-column layout, `margin-md` (1.5rem), `gutter` (1.25rem). Sidebar collapses to icon rail (72px); audit inspector shifts to overlay sheet.
- **Mobile (< 768px):** 4-column layout, `margin` (1rem), `gutter` (1rem). Financial ledgers transition to modular stacked cards with sticky summary headers.

### Interior Spacing Rhythm
- Compact internal paddings (`space-sm` to `space-md`) within data-heavy components maintain visibility of multi-row change detection sets.
- Generous outer section margins (`space-xl`) distinguish primary document clusters from summary statistics.

## Elevation & Depth

Visual hierarchy relies on crisp hairline boundaries backed by soft, diffused environmental ambient occlusion rather than heavy directional drop shadows.

### Elevation Levels
- **Canvas Base (Level 0):** Neutral `#F4F7FB` with optional 24px subtle crosshair dot-matrix/blueprint grid rendered in `#E2E8F0` at 40% opacity.
- **Card Tier 1 (Level 1 - Flat Workstation):** Solid `#FFFFFF` fill bounded by a crisp `1px solid #E6ECF5`. Shadow: `0 1px 3px 0 rgba(10, 26, 51, 0.04), 0 1px 2px -1px rgba(10, 26, 51, 0.02)`.
- **Raised Module (Level 2 - Hover / Active Row / Filter Flyouts):** Solid `#FFFFFF`, `1px solid #D5DFEE`. Shadow: `0 8px 16px -4px rgba(10, 26, 51, 0.08), 0 2px 6px -2px rgba(10, 26, 51, 0.04)`.
- **Command Overlays & Modals (Level 3):** Solid `#FFFFFF`, `1px solid #CBD5E1`. Shadow: `0 20px 28px -6px rgba(10, 26, 51, 0.16), 0 8px 10px -4px rgba(10, 26, 51, 0.08)`.
- **Structural Nav (Level Anchor):** Deep Navy `#0A1A33` with an inline border `1px solid rgba(255, 255, 255, 0.08)`. No cast shadow; anchors screen real estate through tonal weight.

## Shapes

The interface balances sharp industrial angles with modern software ergonomics. Primary containers, cards, and modal sheets use a strict **14px border radius** (`rounded-xl` in this configuration), providing an inviting visual contour without forfeiting architectural rigor.

### Scale Application
- **14px (`rounded-xl`):** All modular structural containers, document diff panes, analysis cards, and chart viewports.
- **8px (`rounded-lg`):** Form input fields, buttons, drop-down menus, icon containers, and floating pills.
- **4px / 6px (`rounded-md`):** Inline status badges, technical tags, and table selection triggers.
- **Pill / Circular (9999px):** Avatar badges, counter pips, and live telemetry pulses.

## Components

### Buttons & Interactive Controls
- **Primary Action:** Solid Electric Blue (`#2563EB`) fill, `#FFFFFF` text, 8px radius, height 38px (compact) or 44px (default). On hover: `#1D4ED8`. Active: subtle inset shadow `0 2px 4px rgba(0,0,0,0.15)`.
- **Secondary / Technical:** Crisp `#FFFFFF` surface, `1px solid #E6ECF5`, text `#0A1A33`. On hover: surface `#F8FAFC`, border `#CBD5E1`.
- **Destructive:** Solid or tinted `#DC2626` variants with immediate visual friction on confirmation dialogues.
- **AI Action Triggers:** Solid `#7C3AED` with micro-glow outline `0 0 0 1px rgba(124, 58, 237, 0.2)` and white icon glyphs.

### Cards & Panels
- **Structure:** Background `#FFFFFF`, 14px border radius, bounded by `1px solid #E6ECF5`.
- **Header Structure:** Explicit separator line dividing module head from body with `1px solid #F1F5F9`, internal padding `space-md` (16px) vertical by `space-lg` (24px) horizontal.
- **Data Density:** Visual cards prioritize clean key-value splits, utilizing `label-sm` in slate gray for descriptors, directly paired with `headline-sm` figures.

### Status Pills & Chips
- Fully contained status tags using an 8px or full-pill radius, rendered with a tinted 10% opacity background, a matching 20% opacity border, and a bold colored label:
  - **Approved:** Background `rgba(22, 163, 74, 0.08)`, border `rgba(22, 163, 74, 0.2)`, text `#15803D`.
  - **Pending Investigation:** Background `rgba(245, 158, 11, 0.1)`, border `rgba(245, 158, 11, 0.25)`, text `#B45309`.
  - **Critical Scope Delta:** Background `rgba(220, 38, 38, 0.08)`, border `rgba(220, 38, 38, 0.2)`, text `#B91C1C`.
  - **AI Detected Change:** Background `rgba(124, 58, 237, 0.08)`, border `rgba(124, 58, 237, 0.25)`, text `#6D28D9`.

### Icon Containers
- Crisp 36x36px or 40x40px duotone frames featuring an 8px border radius.
- Background uses an 8% tint of the parent icon's accent color (e.g., Electric Blue icon seated in `#2563EB0D` container with a fine border `rgba(37, 99, 235, 0.15)`).

### Tables & Data Grid
- **Header:** Sticky `#F8FAFC` row, `1px solid #E6ECF5`, uppercase `label-sm` tracking with `#64748B` typography.
- **Rows:** Alternating subtle hover states (`#F8FAFC`), border-bottom `1px solid #F1F5F9`, line-height calibrated for dense data viewports (48px row height default, 36px condensed).
- **Cells:** Numeric values and CSI MasterFormat document codes explicitly styled in `code-md` (`JetBrains Mono`) for tabular scanning.
- **Cost Variance Columns:** Align right with positive values in `#16A34A` and negative/overrun indicators flagged with Safety Amber (`#F59E0B`) or Critical Red (`#DC2626`).

### Inputs & Form Fields
- Surface `#FFFFFF`, border `1px solid #CBD5E1`, border-radius 8px.
- Focus state: Border switched to `#2563EB` with an external focus ring `0 0 0 3px rgba(37, 99, 235, 0.15)`.
- Integrated spec search fields incorporate a left-aligned monospaced scope code shortcut chip (e.g., `⌘K`).
