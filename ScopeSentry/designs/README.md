## 🎨 Design System Summary ("Blueprint Precision")

- **Aesthetic:** Modern Technical Corporate with Micro-Architectural Tactility. Balances industrial reliability with developer tool velocity (Linear / Vercel style).
- **Core Colors:**
  - **Primary (`#2563EB` / `#004AC6`):** Electric Blue for active states, commit triggers, and AI target selectors.
  - **Secondary (`#0A1A33` / `#505F7B`):** Deep Navy for structural navigation, command headers, and primary hierarchy.
  - **Tertiary (`#F59E0B` / `#784B00`):** Safety Amber for unreviewed scope deltas, field warnings, and budget overrun alerts.
  - **Neutral Canvas (`#F4F7FB`):** Soft slate low-fatigue workspace background.
  - **AI Indicator (`#7C3AED`):** High-voltage violet for optical delta scans and clause comparisons.
- **Typography:**
  - **Headings:** `Plus Jakarta Sans`
  - **Body & Controls:** `Inter`
  - **Spec, Codes & Telemetry:** `JetBrains Mono`
- **Border Radius:**
  - Structural cards / containers: `14px` (`rounded-xl` / `rounded-2xl`)
  - Buttons / Inputs: `8px` (`rounded-lg`)
  - Badges / chips: `4px` - `6px` or full pill (`rounded-full`)
